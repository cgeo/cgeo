c:geo 是 geocaching.com 的非官方客户端，开源、功能完整、随时可用，并为其他地理寻宝平台（如 Opencaching）提供基础支持。无需网页浏览器或导出数据，只需安装即可立即开始使用。

主要功能：
- 在实时地图上查看藏点
- 支持使用谷歌地图或者 OpenStreetMap
- 使用各种条件搜索藏点
- 在线或离线记录你找到的藏点
- 将藏点信息保存到设备上
- 创建并管理路径点
- 使用指南针、地图或其它应用进行导航
- 导入/导出 GPX 文件
- 全面支持 Trackables
- 包括离线地图在内的离线寻宝功能

c:geo 易用且强大，具有很多额外的功能。只需要一个 geocaching.com 或其它 geocaching 平台（比如 Opencaching）的账号，你就可以开始玩耍了。
你可以使用实时地图或其它搜索功能来寻找藏点。

你可以使用内置指南针、地图或其他外部应用（Radar、Google Navigation、StreetView、Locus、Navigon、Sygic 等）导航去藏点或路径点。

你可以直接从 geocaching.com 将藏点信息保存到设备，也可以通过导入 GPX 文件保存，以便随时查看和使用。
你可以管理不同列表中保存的藏点，按需进行排序及过滤。
同时保存藏点和离线地图文件（或静态地图）可以让你在没有网络连接的情况下也能进行寻宝活动（例如：漫游时）。
日志可以在线发布、离线保存后稍后提交，也可以导出为现场笔记（Field Notes）文件。

搜索并发现 Trackables，管理你的 Trackable 清单，并在发布藏点日志时放置一个 Trackable。

如果你在安装或使用 c:geo 的过程中遇到了问题，请先看一下我们的 FAQ（https://faq.cgeo.org）或者查阅用户指南（https://manual.cgeo.org）。
如果以上两个都没有解决你的问题，那就通过电子邮件联系支持吧。

如果您想知道为什么 c:geo 需要所要求的权限，请查看 https://www.cgeo.org/faq#permissions 获取解释。
